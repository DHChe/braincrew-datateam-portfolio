# Triage Labels

Matt Pocock 스킬이 사용하는 다섯 가지 작업 상태를 이 저장소의 GitHub 라벨에 다음과 같이 연결한다.

| 스킬에서 사용하는 상태 | GitHub 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 관리자의 검토가 필요함 |
| `needs-info` | `needs-info` | 추가 정보나 답변을 기다리는 중 |
| `ready-for-agent` | `ready-for-agent` | 에이전트가 바로 구현할 수 있음 |
| `ready-for-human` | `ready-for-human` | 사람의 판단이나 구현이 필요함 |
| `wontfix` | `wontfix` | 진행하지 않기로 결정함 |

스킬이 작업 상태를 지정하면 이 표의 GitHub 라벨을 사용한다. 라벨 이름을 바꾸려면 이 표와 GitHub 라벨을 함께 변경한다.
